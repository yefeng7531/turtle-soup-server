# 🐢 海龟汤 AI 工坊

一个部署在你自己电脑或服务器上的**海龟汤（情境推理谜题）AI 生成器**。它把一套成熟的「海龟汤创作方法论」程序化：**先构思汤底 → 反推汤面 → AI 自动质检（不合格自动回炉修订）→ 可选生成不剧透的汤面插图**。

## ✨ 功能

- **一键出汤**：选主题 / 本格变格 / 清汤红汤黑汤 / 难度 / 篇数（1~5）/ 用途（聚会主持 or 发布文案），产出完整主持包：汤面、汤底、关键线索点、3 级递进提示、8~12 条预判问答表、主持贴士
- **AI 质检**：每篇汤自动按 6 项标准审查（细节映射、多解排除、泄底检查、类型合规、难度匹配、主持一致性），有硬伤自动回炉修订，最多 2 轮
- **汤面插图（可选）**：支持豆包/火山引擎 Seedream（中文出图最好）、硅基流动 Kolors（免费）、Pollinations（免注册）。插图内容只取自汤面，**永远不会剧透汤底**
- **AI 主持模式**：选一篇汤让 AI 当主持人，它只回答「是 / 否 / 与此无关」，可要递进提示，猜中真相即通关公布汤底
- **历史汤库**：所有生成记录本地保存，可查看 / 导出 Markdown / 一键开局
- **广泛兼容**：DeepSeek、硅基流动、Kimi、智谱、通义、OpenRouter、Ollama 本地模型，以及任意 OpenAI 兼容平台，填 Key 即用

# 一、最快上手：先在自己电脑试玩（不用买任何东西）

1. 安装 [Python 3.10+](https://www.python.org/downloads/)（安装时**务必勾选 "Add Python to PATH"**，已装过可跳过）
2. 双击项目里的 **`run.bat`**（Windows）。首次运行会自动装依赖，之后每次双击即启动
3. 浏览器自动打开 `http://127.0.0.1:8000`
4. 到「设置」页填一个对话平台的 API Key（见下一节），即可开始出汤

> Mac / Linux 用户在项目目录执行：
> ```bash
> python3 -m venv .venv && source .venv/bin/activate
> pip install -r requirements.txt
> python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
> ```

# 二、填写 API Key（生成必做）

在网页 **「设置」** 页选择平台并填入对应的 Key：

| 平台 | 注册地址 | 说明 |
|---|---|---|
| **DeepSeek**（推荐） | https://platform.deepseek.com | 注册即送额度，`deepseek-chat` 便宜好用 |
| **硅基流动**（推荐） | https://cloud.siliconflow.cn | 一个 Key 可用几百个模型（DeepSeek/Qwen/GLM…），还带免费生图 |
| Kimi / 智谱 / 通义 / OpenRouter | 各自官网 | 均已内置预设 |
| Ollama 本地模型 | 本机 4343 端口 | 完全免费，需本机装 Ollama |

操作：设置 → 平台预设选 DeepSeek（Key 会自动带出接口地址）→ 粘贴 Key → 点 **「🔄 获取模型列表」**（自动拉取该平台所有可用模型，点击名称即可选用，不会填错）→ 点 **「测试对话连接」** → 保存。

### 生图 Key（可选，只想免费可以先不配）

- **Pollinations**：选它就行，**无需注册任何账号**，零成本
- **硅基流动 Kolors**：注册就送免费额度，Kolors 模型完全免费；如果你对话就用硅基流动，**同一个 Key 直接共用**
- **豆包 / 火山引擎**（中文出图效果最好）：
  1. 打开 https://console.volcengine.com/ark （火山方舟控制台）
  2. 实名认证后，左侧「API Key 管理」→ 创建 API Key
  3. 在「开通管理」里开通 `Doubao-Seedream` 系列模型（新模型有体验额度）
  4. 设置页生图渠道选「豆包/火山引擎」，粘贴 Key，模型名用默认的 `doubao-seedream-4-0-250828`

# 三、部署到云服务器（让任何设备、朋友都能访问）

## 3.1 买服务器（约 50~100 元/年）

1. 任选一家：[腾讯云轻量服务器](https://cloud.tencent.com/product/lighthouse) 或 [阿里云轻量服务器](https://www.aliyun.com/product/swas)，新用户 **2核2G** 的最低配即可（这款程序很轻）
2. 系统镜像选 **Ubuntu 24.04**（或 22.04）
3. 创建后在控制台找到「**防火墙 / 安全组**」→ 添加规则：**放行 TCP 端口 8000**（阿里云叫「防火墙」，腾讯云叫「防火墙」都在服务器详情页里）

## 3.2 部署（全程复制粘贴命令）

**第 1 步**：在服务商控制台点「登录」（网页版终端，不用装任何软件），以 root 身份进入命令行。

**第 2 步**：安装 Docker（一次性，复制粘贴执行）：

```bash
curl -fsSL https://get.docker.com | bash
```

**第 3 步**：把项目传上服务器。最简单的两种方式任选：

- **方式 A（推荐，图形界面）**：安装宝塔面板上传
  ```bash
  wget -O install.sh https://download.bt.cn/install/install_lts.sh && bash install.sh ed8484bec
  ```
  装完会显示面板地址和账号密码。登录宝塔 → 「文件」→ 进入 `/root` → 上传整个项目文件夹的 **zip 压缩包** → 右键解压。
- **方式 B（有 Git）**：把项目传到 GitHub/Gitee 私有仓库，服务器上 `git clone` 下来。

**第 4 步**：进入项目目录，一条命令启动：

```bash
cd /root/turtle-soup-server      # 换成你实际解压出来的目录
bash deploy.sh
```

看到 `✅ 部署完成` 即成功。访问 `http://你的服务器IP:8000`（手机、朋友的电脑都能打开）。

**第 5 步（重要！）**：打开网站 → 「设置」→ **设置访问口令**。否则任何知道你 IP 的人都能用你的 API 额度。

## 3.3 日常维护

| 操作 | 命令 / 方法 |
|---|---|
| 更新代码后重新部署 | 再执行一次 `bash deploy.sh` |
| 看运行日志 | `docker logs -f turtle-soup` |
| 重启 | `docker restart turtle-soup` |
| 备份所有数据 | 下载/复制 `data/` 文件夹（历史记录、配置、插图、数据库全在里面） |
| 忘记口令 | 服务器上编辑 `data/config.json`，把 `access_password` 改成 `""` 后重启 |

# 四、常见问题

| 问题 | 解决 |
|---|---|
| 测试连接报「API Key 无效（401）」 | Key 复制不完整，或 Key 不属于所选平台（如拿 DeepSeek 的 Key 选了硅基流动） |
| 报「触发平台限流（429）」 | 等几秒重试；连续出现说明账户额度用完 |
| 生成中断「模型输出无法解析」 | 换个对话模型（推荐 `deepseek-chat`），或调低创意度 |
| 网页打不开 | 检查安全组是否放行 8000 端口；`docker ps` 看容器是否在运行 |
| 生图失败 | 先点「测试生图连接」看具体中文报错；免费渠道偶尔超时，重试即可 |
| 豆包报 404 | 到火山方舟「开通管理」确认已开通对应模型，模型名与开通的版本一致 |

# 五、生成质量说明

生成流水线严格遵循以下创作方法论（由 `turtle-soup-creator` skill 提炼）：

1. **先汤底后汤面**：先写完整故事再反推谜面，保证汤面每个细节在汤底有出处
2. **新信息法**：绝大部分信息在汤面，唯一关键新信息藏在汤底，玩家用"是/否"提问挖出它
3. **零谎言原则**：汤面每个字都是汤底事实的真子集，误导只靠省略与惯性思维
4. **六项质检**：细节映射 / 多解排除 / 泄底检查 / 类型口味合规 / 难度匹配 / 主持一致性，硬伤自动回炉（最多 2 轮）

即使如此，AI 生成后仍建议你**亲自当一次玩家**（用内置「AI 主持」模式试玩）确认无多解、无泄底再拿去主持。

# 六、项目结构

```
turtle-soup-server/
├── app/
│   ├── main.py        # FastAPI 入口 + 访问口令
│   ├── pipeline.py    # 生成流水线（汤底→汤面→质检回炉）
│   ├── prompts.py     # 创作方法论 → 系统提示词
│   ├── llm.py         # OpenAI 兼容客户端（全平台通用）
│   ├── imagegen.py    # 生图渠道抽象（豆包/硅基/Pollinations/自定义）
│   ├── host.py        # AI 主持
│   ├── config.py      # 平台预设与配置
│   ├── db.py          # SQLite 历史存储
│   └── web/           # 前端界面
├── data/              # 运行数据（config.json / app.db / output插图）——备份这个文件夹即可
├── run.bat            # Windows 本地一键启动
├── deploy.sh          # 服务器一键部署/更新
├── Dockerfile / docker-compose.yml
└── README.md
```
